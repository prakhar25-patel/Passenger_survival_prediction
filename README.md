# Passenger Survival Prediction using Machine Learning

## 📌 Overview

This project focuses on predicting passenger survival using Machine Learning classification algorithms. Multiple classification models were implemented and evaluated to compare their performance on the same dataset.

## 🤖 Models Implemented

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Decision Tree Classifier
* Support Vector Classifier (SVC)
* Naive Bayes

## 📊 Model Performance

| Model               |   Accuracy |
| ------------------- | ---------: |
| SVC                 | **82.38%** |
| Logistic Regression | **80.34%** |
| Naive Bayes         | **77.53%** |
| KNN                 | **77.53%** |
| Decision Tree       | **76.96%** |

SVC achieved the highest accuracy among the evaluated models.
